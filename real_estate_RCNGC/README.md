# Real Estate

Módulo de gestión inmobiliaria desarrollado como proyecto de formación
en Odoo.

## Funcionalidades principales

- Gestión de propiedades
- Gestión de visitas
- Gestión de ofertas
- Gestión de incidencias
- Gestión de imágenes
- Gestión de contratos de venta y alquiler
